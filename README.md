# جسر 2.10

**اسم التطبيق:** جسر  
**الإصدار:** 2.10 — **Android versionCode:** 30  
**فرع الإصدار:** `feature/jesr-2.10-brand-compat`

تطبيق Android عربي للمراسلة المحلية عبر BLE وWi‑Fi Direct، مع محرك توجيه متعدد القفزات. لا يعتمد مسار التوجيه المحلي على Firebase أو خادم مركزي. وجود إذن `INTERNET` في Manifest يدعم مقابس TCP المحلية المستخدمة مع Wi‑Fi Direct، ولا يعني أن الرسائل تُمرر عبر بيانات الهاتف.

## خريطة المصدر

| المسار | المسؤولية |
|---|---|
| `app/index.tsx` | واجهة المحادثات والطلبات والملف الشخصي والمظهر |
| `lib/jesr/engine.ts` | الأصدقاء والطلبات والمحادثات وحالات التسليم وإعادة المحاولة |
| `lib/jesr/identity.ts` | Jesr ID المشتق من المفتاح العام |
| `lib/jesr/protocol.ts` | مغلفات الرسائل والتوقيع والتحقق والتشفير |
| `lib/jesr/runtime.tsx` | ربط محرك المحادثات بالوحدة الأصلية والطابور الدائم |
| `modules/jesr-network/src/index.ts` | واجهة TypeScript لوحدة Expo |
| `modules/jesr-network/android/src/main/java/com/jesr/network/BleMeshTransport.kt` | اكتشاف BLE وGATT |
| `modules/jesr-network/android/src/main/java/com/jesr/network/WifiDirectMeshTransport.kt` | Wi‑Fi Direct وDNS‑SD ومقابس TCP |
| `modules/jesr-network/android/src/main/java/com/jesr/network/MeshRouter.kt` | تمرير الحزم وTTL ومنع التكرار والحلقات وACK |
| `JesrCrypto.kt` و`JesrKeystore.kt` | التشفير الأصلي وحماية التخزين المحلي |

## الهوية والتشفير

هناك معرفان منفصلان:
- **Node ID:** UUID داخلي لعقدة الشبكة والروابط.
- **Jesr ID:** معرف الحساب المشتق من SHA‑256 للمفتاح العام؛ يُستخدم في الأصدقاء ومغلفات المحادثات.

تظهر علامة المطوّر المدمجة `@OTAD_88` في صفحة الملف الشخصي كعنصر SVG ضمن حزمة التطبيق، وليست ملف حقوق نصياً منفصلاً. هذه علامة تعريف مرئية وليست مانعاً مطلقاً لإعادة بناء APK أو تعديله.\n\nيستخدم المصدر libsodium لتوقيع Ed25519 واتفاق المفاتيح X25519 وتشفير XChaCha20‑Poly1305، ويستخدم Android Keystore لحماية ملفات التخزين المحلي بـ AES‑GCM. هذا وصف للتنفيذ الموجود في الكود، وليس شهادة تدقيق أمني مستقل؛ لم يُختبر التوافق التشفيري بين هاتفين فعليين بعد.

يحتفظ محرك المحادثات بطابور دائم محلي لإعادة الإرسال. أما MeshRouter فيمرر مغلفات البيانات المشفرة ولا يحتفظ بمحتوى الرسائل كنص واضح.

## النقل

- BLE للإعلان والمسح واتصال GATT ثنائي الاتجاه ونقل الإطارات الصغيرة.
- Wi‑Fi Direct لاكتشاف الخدمات والاتصال بمقابس TCP محلية.
- MeshRouter يحد الانتشار، ويتحقق من TTL والمسار ومعرفات الحزم لمنع التكرار والحلقات.
- إعادة إرسال رسائل المحادثة عند عودة الوصلة تتم من محرك Jesr وفق سياسة إعادة المحاولة وانتهاء الصلاحية.
- لا يفترض التطبيق أن Android يسمح بالانضمام إلى مجموعات Wi‑Fi Direct متعددة في الوقت نفسه؛ دعم ذلك يختلف حسب الجهاز والشركة المصنّعة.

## فحوص إصدار 2.10

يحتوي `.github/workflows/build-apk.yml` على:
1. التحقق من إعداد Expo.
2. `pnpm check` لفحص TypeScript.
3. `pnpm test` لاختبارات الهوية والبروتوكول.
4. `pnpm lint` لفحص ESLint.
5. Expo Prebuild والتحقق من ربط `jesr-network` و`JesrNetworkModule`.
6. Gradle Release APK بمعمارية `arm64-v8a وarmeabi-v7a وx86_64`.
7. التحقق من توقيع APK واسم «جسر» و`versionName=2.9` و`versionCode=29` ووجود مكتبات libsodium وJNA.
8. رفع artifact باسم `جسر-2.9-Android-APK` عند نجاح جميع الخطوات.

**لا تعتبر APK جاهزًا إلا عندما يكون تشغيل Actions الخاص بآخر commit ناجحًا ويظهر artifact.** نجاح فحوص TypeScript أو الوحدات وحدها لا يثبت نجاح Gradle أو التشغيل على الهاتف.

## مشكلات معروفة لم تُحسم بعد

- قائمة الأجهزة القريبة تعرض Node ID، لكن إضافة الصديق تتطلب Jesr ID؛ تمرير Node ID مباشرة إلى طلب الصداقة غير صحيح، ويلزم تبادل Jesr ID أو فصل الاتصال القريب عن إضافة الصديق.
- شاشة الملف الشخصي موجودة في الواجهة لكن مسار التنقل إليها غير موصول حاليًا.
- نافذة الإضافة لا تُغلق بالنقر خارجها أو بالسحب.
- حقل HEX القابل للتحرير واختيار صورة شخصية غير مكتملين في الواجهة الحالية.
- تعذرت قراءة تفاصيل ملف Figma في هذه الجولة بسبب حد استدعاءات Figma MCP لخطة Starter؛ لذلك لم أغيّر الواجهة اعتمادًا على تخمين.
- لم تُجرَ تجارب BLE/GATT وWi‑Fi Direct على هاتفين، أو تمرير A→B→C على ثلاثة هواتف. كما لم يُجمع Logcat لتحديد سبب الإغلاق المفاجئ الذي أُبلغ عنه سابقًا.

## اختبار الأجهزة

بعد نجاح بناء APK، ثبّت النسخة نفسها على هاتفين، فعّل Bluetooth وWi‑Fi، وافحص اكتشاف BLE واتصال GATT وWi‑Fi Direct وإرسال رسالة مشفرة وACK. بعد ذلك اختبر ثلاثة هواتف A وB وC بحيث يمر الاتصال عبر B، ثم افصل الوسيط وأعده لاختبار استعادة الإرسال. هذه التجارب وحدها تثبت عمل الراديو على العتاد؛ لا تحل محلها المحاكاة أو فحوص البناء.
